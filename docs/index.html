Strategies
                
preserve keeps Vite’s name, nameless reduces it to an
                  8-hex hash (assets/3aefc826.js), codename trades it for a
                  dictionary adjective-noun (assets/onyx-tapir.js). Both sides share the word
                  list; collisions are probed deterministically.

              
Aliases
                
Explicit logical → filename overrides for named entries, validated for
                  collisions before they apply. Everything else follows the strategy.

              
Include / exclude
                
Globs constrain which outputs participate (include defaults to **).
                  Files outside the patterns keep their Vite names — vendor and other targets can be skipped
                  deliberately.

              
Deterministic seed parity
                
A pinned seed yields identical names in the plugin and in PHP recomputation. A mismatched
                  seed fails asset-shield:build and :doctor fast instead of drifting
                  silently between sides.

              
Legend artifact
                
storage/app/asset-shield/legend.json maps every {original, masked}
                  pair. It stays outside public/, is never served, and is regenerated on every
                  build.

              
The honest caveat
                
Names are presentational. Anyone who downloads the asset sees its filename — masking
                  removes structure and framework fingerprints, not the code itself.

            

          


          

            

              
Opaque IDs
                
Every asset gets an HMAC-SHA256 id derived from APP_KEY — deterministic,
                  non-sequential, structurally impossible to guess. Rotating APP_KEY regenerates
                  every id.

              
Signed, expiring URLs
                
runtime.signed_urls signs every URL; runtime.expires (300s
                  default) bounds each link. Verification is constant-time — forged or expired returns
                  403.

              
Registry-only resolution
                
IDs resolve exclusively through the registry. Traversal, absolute paths, and query-as-path
                  are structurally impossible — the registry is the only bridge to a file.

              
Wire behavior
                
Cache-Control: immutable for anonymous assets, clamped to the remaining
                  lifetime for signed ones; correct MIME via the mapper; and
                  X-Content-Type-Options: nosniff everywhere.

              
Route
                
runtime.route_prefix (default assets) mounts the controller at
                  /assets/{id}. With runtime.enabled off, the web server can serve
                  the files directly.

              
Disabled = normal Vite
                
With AssetShield off, @vite(), the manifest, and the dev server behave exactly
                  as upstream. Nothing is replaced unless you opt in.

            

          


          

            

              
Adapter design
                
ObfuscationEngine drives javascript-obfuscator through a thin adapter. When the
                  package is missing, builds warn loudly — and with failOnError they fail rather
                  than silently shipping untouched code.

              
Presets
                
light / balanced / aggressive: documented presets of
                  the underlying engine, picked per threat model. Off by default.

              
Vendor safety
                
Vendor chunks are skipped by default, dynamic imports are preserved, and CSS is never
                  touched — so CDN libraries, chunk boundaries, and stylesheets stay intact.

              
Not encryption
                
Obfuscation raises the cost of reading the bundle; it does not encrypt it. The security
                  model never claims otherwise.

            

          


          

            

              
Source maps
                
Never shipped for protected assets. Enabling them triggers a loud, repeated warning —
                  after that, hosting them is your explicit responsibility.

              
Forbidden files
                
.env, source (.php, .cs), lockfiles, vendor, and
                  storage paths are refused by the MIME/registry guard — even if a registry entry somehow
                  referenced them.

              
CSP & nonces
                
security.csp attaches a strict policy builder, and
                  AssetShield::cspNonce() stitches page-level nonces together without
                  'unsafe-inline'.

              
Key rotation
                
Changing APP_KEY invalidates every opaque id and signature. Rebuild the
                  registry and the cache when you rotate.

            

          


          

            

              
asset-shield:install
                
Publishes config and creates the storage path, prints the exact Vite wiring, and never
                  overwrites user files without confirmation.

              
asset-shield:build
                
Verifies Vite and the manifest, then regenerates and validates the registry (optionally
                  --run the build). Errors are loud, never silent.

              
asset-shield:status
                
Full snapshot — enabled, environment, runtime delivery, route prefix, manifest, registry,
                  signed URLs, expiration, masking, obfuscation + engine, source maps, driver.

              
asset-shield:doctor
                
Inspects APP_ENV, APP_DEBUG, manifest, source maps, node_modules
                  accessibility, .env location, Debugbar, registry validity, legend seed parity,
                  duplicate output names, and toolchain versions.

            

          


          

            

              
PublicDriver
                
Default. Reads the resolved file inside public/build and streams it with the
                  correct headers — PHP-whitelist friendly and simplest to reason about.

              
StreamDriver
                
fpassthru-style lazy streaming with range/conditional support — for larger
                  media and future CDN origination.

              
Reserved
                
X-Accel-Redirect, X-Sendfile, S3, R2, and CDN drivers are designed
                  into the controller contract but intentionally not shipped in the MVP.

              
Why it matters
                
A single controller contract means moving bytes to the edge later requires no rework in
                  routes, registry, or signatures.

Publishes config, creates the registry path, prints the Vite wiring. Never overwrites your files without asking.

          

          

            02
            
asset-shield:build
              
Verifies Vite and the manifest, then regenerates and validates the registry. Build errors are loud, never silent.

          

          

            03
            
asset-shield:status
              
Snapshots the configuration — enabled, environment, runtime delivery, manifest, registry, signed URLs, expiration, masking, obfuscation, source maps, driver.

          

          

            04
            
asset-shield:doctor
              
Inspects APP_ENV, debug flags, manifest, maps, node_modules, .env placement, Debugbar, and registry validity. Actionable warnings.

        Install & docs
        
Ship a build. Protect it. In four lines.

      

      

        

          

            
            quickstart
          

          

            
$ composer require shamimstack/asset-shield

            
$ npm i -D @asset-shield/vite-plugin

            
$ php artisan asset-shield:install

            
 

            
// config/asset-shield.php — opt-in hardening

            
'mask' => [ 'enabled' => true, 'strategy' => 'codename' ],

            
'obfuscation' => [ 'enabled' => true, 'preset' => 'balanced' ]

            
 

            
// vite.config.js

            
import { assetShieldVite } from '@asset-shield/vite-plugin';

            
plugins: [ laravel({ input: […], refresh: true }), assetShieldVite() ]

            
 

            
$ npm run build && php artisan asset-shield:build

            
✔ protected build ready
